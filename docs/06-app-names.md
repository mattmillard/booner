# App Name Suggestions

Criteria: short, memorable, not taken by a major hunting brand, hints at the core edge (terrain + wind + AI planning), works as a domain/package id. **Check USPTO (tmsearch.uspto.gov), app stores, and domain availability before committing** — none of these were checked yet.

## Top picks

| Name | Why | Package id |
|---|---|---|
| **Thermal** | The thing no competitor models well. One word, owns the concept. | `app.thermal.hunt` |
| **Windline** | Wind + the line you walk to the stand. Signature feature in the name. | `app.windline` |
| **Bedrock** | Bedding areas + terrain (LiDAR). Solid, trustworthy. | `app.bedrock.hunt` |
| **Scentline** | Scent cone + entry route. Very bowhunter. | `app.scentline` |
| **Draw & Bench** | Two terrain features deer use ("draw", "bench"). Distinctive. | `app.drawbench` |

## Terrain / reading-the-land

- **Contour** — clean, topo-native.
- **Ridgecraft** — reading ridges is a craft.
- **Saddle** — the classic funnel; short and catchy.
- **Pinchpoint** — literal, hunters get it instantly.
- **Hillshade** — the LiDAR look.
- **Benchmark** — survey term + "bench" terrain feature + a pun on being the best.

## Wind / scent / thermals

- **Downwind** / **Upwind**
- **Thermal Hub**
- **Crosswind** — the ideal stand wind.
- **Scent Cone**
- **Driftline** — where scent drifts; also where debris collects on a creek.

## Planning / AI

- **Stand Forge** — nods to Spartan Forge; too close, probably avoid.
- **Hunt Architect**
- **Deerpath AI**
- **Tactician**
- **Quiet Approach** — the core bowhunting rule: get in and out undetected.

## Missouri / local flavor

- **Show-Me Hunt** / **ShowMe Maps** — "Show-Me State" pun, great for MO launch, limits later expansion.
- **Big Muddy** — Missouri River nickname; the bluffs and bottoms of Callaway/Cooper.
- **Katy Line** — Katy Trail runs through both counties; local, not obvious to outsiders.

## Veteran / outdoor-therapy tie-in (if it lives under Veterans Outdoor Therapy)

- **Overwatch** — military + stand-hunting, but **conflicts with onX's "Overwatch x Rescue" SOS partner**; avoid.
- **Rally Point** — group meets/hunt camp; military flavor.
- **Recon** — scouting = recon. Common word; hard to trademark.
- **FOB** (Forward Operating Base) — stand = FOB. Niche.
- **Treeline Recon**

## Recommendation

1. **Windline** — describes the feature neither competitor has (wind- and thermal-aware stands and routes), sounds like a product, easy to say.
2. **Thermal** — strongest single word, but it may clash with thermal-optics brands; check trademarks first.
3. **Benchmark** — clever triple meaning, very brandable.

The codebase uses the placeholder `hunt-app` until a name is chosen. Renaming is one search-and-replace in phase 0.
